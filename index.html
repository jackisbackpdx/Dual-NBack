    HELP

    Dual N-Back exercise is a scientifically proven way of improving your fluid intelligence. Fluid intelligence refers to the ability to reason and to solve new problems independently of previously acquired knowledge.

    As the first part of the game's name Dual suggests, the idea is to keep track of two individual things while playing: the flashing square's position and the letter sound. The last part of the name N-Back suggests how many square's positions and letter sounds you should keep track of. For example if N = 1 (i.e. Dual 1-Back), you should keep track of the previous square's position and letter sound. If N = 2 (i.e. Dual 2-Back), you should keep track of two previous square's positions and letter sounds and so on.

    DUAL 1-BACK

    The game presents you a flashing square and a letter sound every 3 seconds. In Dual 1-back (i.e. N = 1), you have a match if the square's position is the same as the previous square's position. Similarly, you have a match if the letter sound is the same as the previous letter sound.

    Note that square positions and letter sounds are two individual things to keep track of. Flashing squares and letters do not match with each other in any way.

    DUAL 2-BACK

    If you haven't played Dual N-Back before, you will find that even Dual 2-Back is quite difficult. Don't worry, you'll get better soon and it is actually playing at the limit of your ability when you increase your fluid intelligence.

    In Dual 2-Back (i.e. N = 2), you have a match if the flashing square's position is the same as the square's position shown two square's earlier. Similarly, you have a match if the letter sound is the same as the letter sound presented two letter sounds earlier.

    HITTING TARGETS

    You should press the visual button (eye) or the audio button (ear) when you think the flashing square's position or letter sound match respectively.

    GAMEPLAY

    One game round presents 20+N flashing square's positions and letter sounds. So, for example if N = 1 (i.e. Dual 1-Back), you would be presented 21 square's position and letter sound pairs. After each round N is increased by one if there were less than three square's position match mistakes and less than three letter sound match mistakes. On the other hand N is decreased by one if there were more than five mistakes. In all other cases N remains the same for the next round.

    There can be two kinds of mistakes: 1) not pressing audio (ear) or visual (eye) button when should have and 2) pressing audio or visual button when shouldn't have.

    Notice that the square's position and letter sound may match at the same time and when this happens, both buttons should be pressed before next position and letter is presented.

    DAILY FIRST N

    Setting 'DAILY FIRST N' sets N for the first game each day. SAME AS YESTERDAY'S LAST means that N is the same as where you left off in the last game, ALWAYS 1 sets N always to one and ALWAYS MY BEST sets N to the highest N you've ever reached.

    TIP: DON'T USE MEMORY TRICKS

    The point is to remember the sequence of flashing square's positions and letter sounds without using memory tricks because training for better fluid intelligence is not the same as learning memory tricks. N increasing and decreasing between rounds is helping you to achieve this: N changes so often that you won't stay long enough on certain levels just to learn how to get better only on those levels (i.e. learn memory tricks for those levels only).

    TIP: PROGRESS MATTERS

    You will have bad days which may be caused by a number of things (for example lack of sleep or stress). However, be persistent. You will get better over time.

    Your starting N level is not important. What matters is your improvement in the long run. It is recommended that you play 20 rounds 4-5 days per week for the most optimal benefit.
